"# Simple Calculator Application"

This simple calculator application was built using HTML, CSS, and JavaScript (vanilla). The project aims to demonstrate the creation of a basic user interface and implementing essential functionality using front-end technologies.

# Features
Basic arithmetic operations: addition (+), subtraction (-), multiplication (*), and division (/).
Evaluation of expressions when the '=' button is pressed.
Clear functionality to reset the display.
Subtle gradient text effect on the title for visual appeal.

# Technologies
HTML: Used for structuring the calculator's layout and elements.
CSS: Applied styles and a gradient text effect to the title.
JavaScript: Implemented the calculator's logic, event handling, and expression evaluation.

# Deployment

# Usage
Open the index.html file in a web browser.
Enter numbers and select the desired arithmetic operation using the corresponding buttons.
Press the '=' button to evaluate the expression.
Click the 'clear' button to reset the display.
